# 说明
这题就是知道工件在机器人基座坐标系下的位姿，以及夹爪相对于法兰的安装位姿，计算法兰在基座坐标系下的位姿

# 环境

- Python 3.12
- NumPy
- SciPy

安装依赖：

pip install numpy scipy

# 输入参数

工件在基座坐标系下的位姿：
  平移：(0.520, -0.180, 0.120) m
  RPY：(180, 0, -30) deg

夹爪相对于法兰的安装位姿：
  平移：(0.000, 0.000, 0.165) m
  RPY：(0, 0, 45) deg

并且题目说了工件坐标系与夹爪夹持中心重合

# 数学思考

采用齐次变换矩阵表示机器人坐标系之间的位姿关系

公式：
T_base_flange = T_base_object * inverse(T_flange_gripper)
T_base_object 表示工件在机器人基座坐标系下的位姿
T_flange_gripper 表示夹爪相对于法兰的安装位姿

# 两种计算方法

方法一：旋转矩阵路径。

使用 NumPy 构建 4×4 齐次变换矩阵，通过矩阵乘法和矩阵求逆计算法兰位姿。

方法二：四元数路径

使用 SciPy Rotation 进行四元数转换、旋转组合和向量旋转，独立计算法兰的姿态与平移

最后将两种计算结果转换为齐次变换矩阵，比较最大绝对误差

# 最终结果

平移：(0.520000, -0.180000, 0.285000) m

RPY：(180, 0, 15) deg

四元数：(0.9914448614, 0.1305261922, 0, 0)

两种方法最大误差约为： 2.22e-16
