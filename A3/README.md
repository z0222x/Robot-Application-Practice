# 介绍

本题基于 Python Socket 网络编程实现一个简单的多客户端聊天室，采用 TCP 协议进行客户端与服务器之间的通信。
服务器负责接收多个客户端的连接，为每个客户端创建独立线程，实现多个用户同时在线聊天
客户端登录后可以发送消息，服务器接收消息并将其广播给其他用户

# 功能

服务器监听  创建 TCP Socket，绑定 IP 地址和端口，监听客户端连接请求 
多客户端接入  使用 accept() 接收客户端连接，为每个客户端创建独立线程 
在线用户管理 使用字典保存在线用户及其 Socket 连接 
消息广播  服务器接收客户端消息后，将消息转发给其他用户 
系统通知  用户加入或退出聊天室时，服务器广播相应的消息 
退出 客户端输入 退出 离开聊天室，服务器删除对应的用户连接




# TCP粘包与拆包处理

TCP 是面向字节流的传输协议，本身没有应用层消息边界, 所以连续发送的多条消息可能被一次接收，也可能一条消息被分多次接收，这就是 TCP 粘包与拆包问题

我用的是换行符分隔法解决此问题

客户端发送消息时，在消息末尾添加换行符

服务器使用 makefile() 创建按行读取的文件对象, 再通过 readline() 读取完整的一行消息

客户端接收服务器消息时也使用相同的读取方式

用 \n 作为消息结束标志，使接收方能够区分连续传输的不同消息，以此解决 TCP 粘包与拆包问题
